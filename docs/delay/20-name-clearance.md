# Name clearance note: "Dwell" / "BMO Dwell"

Searched on AURORA on 2026-09-20: a web search, then a wordmark search of the
USPTO trademark register, run in a browser. This is not legal advice and not a
substitute for a proper clearance search.

**This note is the conclusion only.** The working version listed the marks and
the products the searches turned up. It was cut down on 2026-10-01: the
repository is public, and other parties' names stay out of it. The counts
below are what that version recorded; nothing was searched again.

## What was found

- **No audio plugin, pedal or hardware unit** was found shipping under the
  name "Dwell", in plugin directories or at pedal retailers.
- **USPTO, wordmark `dwell`:** 385 marks. All seven result pages were scanned
  and filtered to Nice classes 9 and 15.
  - Class 15 (musical instruments): none.
  - Class 9, the exact word, live: one, held by a home-design media brand, for
    a website featuring downloadable videos. Not audio software.
  - Class 9, the exact word, dead: four, abandoned or cancelled. None was an
    audio effect.
  - Class 9, live, the word inside a longer mark: ten, two of them pending.
    All are home, property, retail-sensor or wellbeing goods, except one
    pending mark for downloadable sound recordings. None is an audio effect,
    a plugin or music software.
- **"Dwell" is a generic control label** in this category: it is the usual
  name for a knob on spring reverbs and on some reverb and delay pedals. That
  makes it unlikely anyone holds the word exclusively for a control, and for
  the same reason it is a weak mark by itself. "BMO Dwell" is the unit to
  ship and, if it comes to that, to file.

## Risk read: low to medium

No live US mark for the word covers audio software or musical instruments. The
residue is that the nearest live class 9 mark belongs to a well-known
home-design brand. Shipping as "BMO Dwell" helps.

## Not checked

EUIPO / TMview, the UK IPO, the WIPO Global Brand Database, and common-law
(unregistered) use. A real clearance needs those, run by someone qualified.
Not legal advice.
